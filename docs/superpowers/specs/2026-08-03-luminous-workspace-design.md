# Luminous Workspace 全站动态皮肤设计

## 目标

将当前分散、单调且层级不足的 Aurora 样式统一成一套适合研发管理场景的白色动态工作台皮肤。在不改变业务逻辑、不替换成熟表单控件、不收窄内容画布的前提下，提升页面辨识度、状态反馈、空状态体验和整体精致度。

## 参考来源与取舍

- MotionSites：借鉴动效节奏、空间层次和视觉氛围，不引入运行时依赖。
- React Bits：借鉴光效、背景、文字、加载和 Dock 等可组合动效，将需要的实现改写为项目内组件。
- Aceternity UI：借鉴 Glowing Effect、Animated Tabs、Stateful Button、Bento Grid、Empty States、File Upload 等交互模式。
- Uiverse：借鉴按钮、输入、开关和加载器的局部微交互，逐项审查键盘、焦点、性能和许可。

不直接混装四套组件库。Semi UI 继续负责 DatePicker、Select、Table、Modal、Dropdown、Toast 等可访问交互；项目只在视觉层和反馈层增强。

## 视觉语言

- 底色：近白冷灰，不用纯白铺满，也不使用大面积高饱和渐变。
- 品牌色：深蓝为主、紫色为辅助、青色仅用于高光。
- 表面：三层 surface；普通卡片、悬浮卡片、弹层分别拥有不同透明度、边框和阴影。
- 光效：静态环境光位于画布边缘；可交互光效只在 hover、focus、loading、active 时出现。
- 圆角：控件 10px、卡片 16px、浮层 20px，避免所有内容使用同一圆角。
- 字体：Geist Variable；标题使用更紧字距和分级字重，正文保持 14px 高可读性。
- 动效：快速状态 140–180ms；页面进入 220–280ms；弹层 260–320ms；不使用无限循环装饰动画。

## 组件体系

### 基础层

- `LuminousSurface`：普通、悬浮、强调三种表面，支持 spotlight 与交互边框。
- `LuminousEmptyState`：统一图形、标题、描述、主次操作和进入动画。
- `LuminousSkeleton`：柔和高光扫描，不改变布局尺寸。
- `WorkspaceButton`：状态按钮支持 loading、success、danger 和按压反馈。
- `WorkspaceCard`：使用 surface 语义，hover 只提升小型可交互卡片，大容器不整体漂移。

### 框架层

- Dock 保留现有 macOS 距离衰减动效，统一背景与光影。
- Header 使用半透明表面、低干扰搜索框和更清晰的操作分区。
- 路由历史标签使用滑动高光指示器，非活动标签保持低对比度。
- 页面过渡采用轻微上浮和模糊消退，不遮挡内容、不影响滚动位置。

### 登录页

- 桌面端使用全视口双栏：左侧为研发工作台能力叙事，右侧为白色账号登录区，不再使用居中的单卡片背景。
- 左侧采用 React Bits Galaxy 的 OGL 星场算法作为装饰层，使用低密度、低转速和蓝色调，不参与表单交互。
- WebGL 不可用时保留深蓝渐变背景；系统开启“减少动态效果”后停止持续渲染和鼠标跟随。
- 小于 820px 时隐藏 Galaxy 视觉区，只保留品牌、表单与本地数据说明，避免移动端性能和空间浪费。
- 登录接口、错误文案、保持登录、密码显隐、原受保护路由返回和首次改密逻辑保持不变。

### 数据与表单层

- 表格默认铺满容器；表头使用轻微色层，行 hover 使用局部高亮，不缩放整表。
- 输入、下拉和日期控件统一边框、focus ring、placeholder、禁用和错误状态。
- 弹窗统一 20px 圆角、头部层次、正文安全区和底部操作间距。
- 空结果、加载、错误和无权限状态使用统一反馈组件。

## 响应式与可访问性

- 所有页面 `width: 100%`、`min-width: 0`，不得恢复固定窄画布。
- Grid 使用 `repeat(auto-fit, minmax())` 或明确断点；工具栏使用 flex-wrap。
- 低于 720px 时弹窗表单单列，卡片减少 blur 与阴影，Dock 使用已有紧凑规则。
- `prefers-reduced-motion` 下关闭位移、光效扫描和持续动画。
- 保留可见 focus outline；文字与背景满足工作界面所需对比度。

## 验收标准

- 全站按钮、输入、选择器、日期、表格、弹窗、下拉、通知、卡片和空状态视觉一致。
- 主要路由在 1280、1440、1920 宽度无页面级横向滚动，表格真实 DOM 铺满容器。
- 没有 `transition: all`、`outline: none/0`、原生日期控件和原生 select 回流。
- reduced-motion、键盘操作和读屏语义不退化。
- 前端 typecheck、目标单测、生产构建和浏览器视觉检查通过。
