# 后端稳定性、知识库回收站与 Windows 本地语义模型设计

## 目标

修复当前后端连接池与提醒调度故障，补全知识库回收站的永久删除和清空闭环，并让本地语义模型在 Windows 桌面环境中可安装、可降级、可观察。

## 一、后端稳定性

- Prisma 生产连接池固定最多 5 个连接，给数据库维护和桌面进程保留余量。
- 普通提醒扫描和员工周计划提醒同步由单一维护协调器按“同步提醒规则 → 扫描到期提醒”顺序每 30 秒执行；两个子服务不再各自注册同相位定时器。
- 协调器和两个子服务都保留进程内防重入；两个数据库阶段继续共享 `pg_try_advisory_xact_lock` 以避免读写竞态，没有取得锁时返回 `skipped`，不阻塞事务。
- 交互事务显式配置 `maxWait` 与 `timeout`，不能用单纯延长超时掩盖锁等待。
- 本地向量模型未准备的日志按服务生命周期去重，全文检索降级继续可用。

## 二、知识库回收站

### 行为

- 回收站支持单项恢复、单项永久删除、批量恢复、批量永久删除和清空回收站。
- 所有永久删除都必须二次确认；清空操作明确显示待删除数量。
- 只有 `TRASHED` 文档允许永久删除，活动文档调用永久删除接口返回冲突错误。
- 上传文档永久删除时清理文档、历史版本、索引块、文件资产、文件版本、上传原件和预览缓存。
- 本地文件夹文档永久删除时清理知识库记录、索引、预览和扫描映射，不删除用户磁盘上的原始文件。
- 清空操作逐项返回删除数量；任何存储清理失败都不能静默伪装成功。

### 界面

- 回收站列表顶部显示标题、数量、批量操作和“清空回收站”。
- 回收站隐藏上传入口；详情只读，隐藏保存状态、标签编辑和附件上传。
- 右侧详情顶部使用明确的“恢复”和“永久删除”按钮；危险操作统一红色语义。
- 空态改为“回收站为空”，并说明移入回收站的文件会出现在这里。
- 三栏保持现有飞书式浅色工作区，但统一边距、按钮高度、标题层级和滚动区域。

## 三、Windows 本地语义模型

- 模型设置从“本地文件夹”移到知识库检索设置区域；本地文件夹页只负责目录扫描与同步。
- UI 名称改为“启用本地语义检索”，解释它不是下载本地文件。
- Windows x64/arm64 优先使用 `onnxruntime-node` 原生 CPU 后端；原生绑定不可加载时回退到 `onnxruntime-web` WASM。WASM 使用 Node 磁盘 custom cache，不依赖 web bundle 中不可用的浏览器/FS cache。
- 模型缓存默认放在操作系统用户数据目录；开发模式可继续由 `LOCAL_AI_MODEL_CACHE` 覆盖。
- custom cache 使用 SHA-256 安全键、原子写入和损坏条目自动忽略；下载完成后重启应用，`local_files_only` 必须能从同一路径读取，不能再次依赖网络。
- 下载状态至少覆盖：未准备、下载中、加载中、可用、失败；错误只返回用户可读摘要，不展示模块堆栈。
- 下载成功后自动触发现有知识库重新索引，并展示重新索引状态。
- 模型不可用时全文检索继续工作；同一错误不反复刷后台日志。

## 数据安全

- 永久删除不可恢复，前端必须确认，后端必须验证状态。
- 永久删除本地扫描文档永远不调用操作系统删除原件。
- 存储键必须来自数据库且经过现有 `StoragePort` 路径校验，接口不接受客户端传入存储路径。
- 模型向量计算在本机完成；最终生成回答仍遵循现有 DeepSeek 数据范围。

## 验收

- 数据库连接池不会超过配置上限，提醒任务重入和锁竞争不会产生事务超时日志。
- 回收站可恢复、永久删除、批量处理和清空，上传原件被清理，本地原件保留。
- Windows x64 可启用语义模型；原生运行库异常时可回退 WASM。
- 前后端定向测试、类型检查、构建通过，真实浏览器完成回收站与模型状态验收。
