# 竖向 macOS Dock 导航设计规格

## 1. 目标

将当前左侧图标栏重构为参考 macOS 竖向 Dock 的导航组件：保留全高半透明玻璃轨道，以彩色应用图标、连续距离放大、邻近图标让位、运行指示点和工具分组形成明确的 Dock 感，同时保持现有路由、权限过滤和白色 Aurora 页面体系不变。

本次不复制 Safari、微信等第三方图标，也不使用受版权限制的 macOS 系统资源。工作台各模块使用项目自有的彩色 SVG 应用图标。

## 2. 视觉结构

### 2.1 玻璃轨道

- Dock 固定在工作区左侧，高度与可视窗口一致，宽度基准为 82px。
- 使用半透明玻璃背景、24px 模糊、轻微饱和度、内高光、右侧细描边和柔和投影。
- 轨道与页面内容保持明显材质差异，但不改变主内容区现有背景与布局。
- 窗口宽度低于 900px 时进入紧凑模式，轨道宽度降为 70px。

### 2.2 分组

导航分为三组：

1. 核心应用：工作台、我的工作、项目、员工。
2. 内容应用：文档与知识库、多维表格、日历。
3. 工具应用：搜索、系统管理。

内容应用与工具应用之间使用低对比度玻璃分隔线。系统管理继续根据当前用户权限动态显示，不改变现有权限判断。

### 2.3 彩色应用图标

- 每个模块拥有独立的渐变配色和语义图形，统一使用圆角 Squircle 外形。
- 图标由本地 SVG/React 组件构成，不加载网络资源。
- 图标光照方向、圆角、边缘高光和投影保持一致。
- 图形必须在 40px 基础尺寸和最大放大尺寸下保持清晰。
- 图标颜色遵循模块语义，但不与页面状态色混用。

## 3. 交互与动效

### 3.1 距离感应放大

- 使用 Framer Motion 的 `MotionValue`、`useTransform` 和弹簧动画实现，不使用 Canvas。
- Dock 监听指针在轨道内的纵向坐标，每个图标根据自身中心与指针的距离连续计算缩放。
- 基础图标尺寸为 46px；指针正对图标时最大约为 76px，缩放约 1.65 倍。
- 影响半径覆盖上下约两个图标；距离越远，缩放连续衰减至 1。
- 图标容器同时产生纵向位移，让邻近图标自然让位，不能只通过覆盖式 `scale()` 叠在一起。
- 指针离开 Dock 后，所有图标通过 spring 平滑复位。
- 建议弹簧参数：`mass 0.12`、`stiffness 180`、`damping 16`，最终以浏览器实测无抖动为准。

### 3.2 状态反馈

- 当前路由使用图标左侧 4px 运行指示点，不再使用蓝色双层描边。
- Hover 显示位于 Dock 右侧的中文名称气泡。
- Pointer down 时图标轻微压缩，释放后回弹。
- 路由切换时目标图标执行一次轻量弹跳，不循环播放。
- 通知角标保留扩展位置，但本次只实现组件能力，不新增业务通知映射。

### 3.3 键盘与减少动画

- 每个导航项保持真实 `NavLink`，支持 Tab、Enter、Cmd/Ctrl 点击和浏览器链接语义。
- `:focus-visible` 时显示名称气泡和清晰焦点环。
- `prefers-reduced-motion: reduce` 下禁用距离放大、弹跳和位移，只保留颜色、焦点和当前路由指示。
- 自定义气泡与原生 `title` 不同时启用，避免双重提示。

## 4. 窗口高度策略

- Dock 容量由窗口高度决定，不再只根据窗口宽度响应。
- 高度足够时所有组完整展示。
- 高度低于 720px 时进入紧凑模式：基础图标、组间距和轨道内边距同步缩小。
- 高度仍不足时，应用组在轨道内部纵向滚动；滚动条隐藏但滚轮、触控板和键盘滚动可用。
- 工具组保持在可滚动内容中，避免固定底部覆盖应用项目。
- 禁止任何菜单项超出 Dock 后被 `.app-shell { overflow: hidden }` 裁切。

## 5. 组件边界

### `WorkspaceNavigation`

- 负责权限过滤、分组、路由激活判断和 Dock 指针坐标。
- 不负责绘制具体业务图标细节。

### `DockItem`

- 负责单个导航项的距离计算、spring、焦点、Tooltip、当前状态和点击反馈。
- 输入为导航元数据、图标组件、激活状态和共享指针 MotionValue。

### `WorkspaceDockIcon`

- 根据 `NavigationIcon` 输出项目自有彩色 SVG 图标。
- 图标组件只负责图形，不读取路由或权限状态。

### 样式与 Token

- Dock 材质、尺寸、阴影和指示点继续放入工作区 Token。
- `AppShell.less` 只负责布局、玻璃轨道、分组、Tooltip 和响应式规则。
- 动态缩放与位移由 Framer Motion inline motion style 管理，避免生成大量状态 class。

## 6. 数据与状态流

1. `WorkspaceNavigation` 从认证 Store 获取用户权限并生成可见分组。
2. 指针进入 Dock 后更新共享 `mouseY` MotionValue。
3. 每个 `DockItem` 读取自身中心位置，计算与 `mouseY` 的距离。
4. `useTransform` 把距离映射为尺寸、缩放和位移目标；spring 负责平滑过渡。
5. 路由状态仍由 `NavLink` 和现有 `isActivePath` 决定。
6. 指针离开、窗口 resize 或组件卸载时清除悬浮状态并恢复基础尺寸。

## 7. 验收标准

### 视觉

- Dock 是全高玻璃轨道，不再呈现为普通后台侧栏。
- 9 个模块具有独立且一致的彩色应用图标。
- 当前路由只使用左侧小圆点和轻微提亮，不出现厚重蓝色描边。
- 主内容区和 Header 不被 Dock 放大图标遮挡。

### 动效

- 指针沿 Dock 移动时，缩放连续，无三级跳变。
- 当前图标放大时，上下至少两个邻近图标同步缩放并让位。
- 快速移动和离开 Dock 时没有卡顿、残留 transform 或闪跳。
- reduced-motion 模式下无放大和位移动画。

### 布局

- 1280×720、1280×600、1024×600 和 900×600 下所有导航项均可访问。
- 600px 高度时最后一个导航项不会落到视口外，也不会被外层裁切。
- Tooltip 不被 Header、主内容区或视口边缘遮挡。

### 可访问性与回归

- 所有导航仍是可聚焦链接，具有唯一可访问名称和当前页面状态。
- 键盘聚焦时可看到名称和焦点状态。
- 权限不足的用户不显示系统管理入口。
- 现有路由地址、页面加载逻辑和顶部 Header 行为不改变。

## 8. 测试范围

- 单元测试：导航分组、管理员权限过滤、当前路由、图标映射、reduced-motion 分支。
- 组件测试：指针进入/离开、聚焦 Tooltip、分组线、当前状态指示。
- 静态规则：禁止回退为固定三级 `:hover + sibling` 放大方案。
- 浏览器测试：1280×720 与 1280×600 的边界测量、最后一项可见、悬浮波峰和键盘访问。
- 构建验证：frontend lint、typecheck、focused tests、production build 和 `git diff --check`。

## 9. 非本次范围

- 不复制任何真实 macOS、Safari、微信或其他第三方应用图标。
- 不实现任意拖拽排序和服务端个性化持久化。
- 不实现右键最近项目、最近文档等业务菜单。
- 不修改主内容页面、Header、权限模型或后端接口。
