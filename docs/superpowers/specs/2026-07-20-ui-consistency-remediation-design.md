# UI 一致性修复设计

## 目标

将当前混合的世界杯旧主题、Semi Design、Radix/shadcn 和原生表单控件收敛为单一的飞书式浅色桌面工作台体验，修复用户截图中工作台、设置、搜索、项目、日历、知识库、多维表格和全局弹窗的视觉及交互问题。

## 设计决策

- 只保留浅色工作台主题；历史主题值即使仍保存在 localStorage，也统一解析为 `classic`。
- 页面、弹窗、日期、下拉、按钮和消息反馈统一使用 Semi Design；已有业务逻辑保持不变。
- 保留 shadcn 组件文件供尚未迁移页面兼容，但本次截图涉及的入口不再使用它们。
- 页面画布使用 `#f5f6f7`，内容面使用白色，品牌色使用 `#3370ff`，正文、次级文字、边框和状态色全部来自工作台令牌。
- Modal 使用标准 footer；主要操作右对齐，操作间距 8px，footer 水平 24px、垂直 16px，不再把按钮贴在内容底部。
- 日期使用 Semi `DatePicker`，下拉使用 Semi `Select`；日历使用中文 locale。
- 数据不足时不使用固定大高度制造空白，表格和分页跟随内容。

## 页面设计

### 工作台、设置和搜索

移除 `.app-page` 的深色渐变和旧体育主题覆盖，统一为浅色画布、1280px 内容宽度和 24px 页面边距。首页快捷入口使用轻量白色卡片，设置使用三张清晰的设置卡片，搜索使用统一表面和清晰的空状态。

### 项目和日历

项目列表取消 460px 固定最小高度，表格一条数据时不再留下大块空白。日历接入中文 locale，工具栏允许合理换行，外部同步说明不再挤压主操作。

### 弹窗

新建项目、新建任务、新建知识空间、AI 问答、多维表格模板和日程表单均采用统一内容区与 footer。表单输入高度 32px，标签与控件间距 6px，字段组间距 16px。

## 交互与可访问性

- 所有输入必须有可关联标签或 `aria-label`。
- 焦点使用 `focus-visible`，不无替代地移除 outline。
- 禁用按钮旁提供可读原因，不能只依赖灰色表达。
- 下拉宽度至少与触发器一致，日期展示遵循中文格式。
- 弹窗支持 Esc 和右上角关闭，创建类弹窗同时提供取消按钮。

## 验收

- 主题默认且始终为浅色，不再出现深灰绿内容区域和黄色主按钮。
- 截图涉及的新建项目、任务、知识空间和模板弹窗有标准底部间距与取消按钮。
- 任务日期、优先级、状态和日历日期均使用 Semi 控件。
- 日历显示中文年月及星期。
- 项目一条记录时列表容器随内容收缩。
- 前端单测、类型检查、构建通过，并完成本地浏览器截图检查。
