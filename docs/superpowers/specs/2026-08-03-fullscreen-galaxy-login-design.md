# 全屏 Galaxy 登录页设计

## 目标

将现有仅覆盖登录页左栏的 React Bits Galaxy 背景扩展到整个视口，并把右侧登录区域从实色面板改为可透出星空的半透明玻璃卡。登录流程、字段、校验和响应式信息架构保持不变。

## 视觉结构

1. `GalaxyBackground` 作为登录页最外层的绝对定位背景，覆盖完整视口。
2. 页面内容层继续使用左右两栏布局，但两栏本身不再铺设不透明背景。
3. 左侧介绍文案使用轻量局部暗色渐变保证对比度，不形成明显的半屏色块。
4. 右侧登录卡使用白色半透明玻璃材质：半透明底色、背景模糊、浅色描边和柔和阴影。
5. 右侧登录区域外围保持透明，使 Galaxy 在登录卡周围连续可见。

## 交互与层级

- Galaxy Canvas 位于最底层并保持全屏尺寸。
- 非交互装饰与左侧文案层不拦截指针事件，让鼠标排斥效果可覆盖背景区域。
- 登录卡及表单恢复指针事件，输入、密码显示、保持登录和提交行为不受影响。
- 登录卡上方的星空不应降低文本与输入控件的可读性。
- 遵循系统 `prefers-reduced-motion` 设置：关闭持续动画和鼠标交互，但保留静态背景。

## 响应式行为

- 桌面端保留左右信息结构，Galaxy 覆盖完整窗口。
- 窄屏继续隐藏左侧介绍内容，但不隐藏 Galaxy。
- 移动端登录卡保持合理边距和可读宽度，背景仍为全屏星空。
- 不使用固定视口宽度，布局依赖 Grid、Flex、`minmax()` 和 `clamp()`。

## 验收标准

1. Galaxy 容器的边界与浏览器视口一致，不再等于左栏宽度。
2. 右侧登录区域计算背景为透明，星空在登录卡周围连续可见。
3. 登录卡背景 alpha 小于 1，并启用 `backdrop-filter`。
4. 登录卡内全部交互控件可点击、可聚焦、可提交。
5. 1440×900 桌面视口和 390×844 移动视口无横向溢出。
6. 登录页单元测试、Galaxy 浏览器测试、类型检查和生产构建通过。

## 非目标

- 不修改账号登录 API、Token、权限或路由逻辑。
- 不重新设计登录表单字段和文案。
- 不修改工作台登录后的页面皮肤。
