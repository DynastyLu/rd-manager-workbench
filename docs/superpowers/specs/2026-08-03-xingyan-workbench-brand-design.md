# “星研工作台”品牌更名设计

## 目标

将产品对用户展示的名称统一由“研发主管工作台”或作为产品名使用的“研发工作台”调整为“星研工作台”。名称不再限定主管角色，并与 Galaxy 登录视觉及 NOVA AI 助手形成统一品牌体系。

## 品牌体系

- 产品名称：星研工作台
- AI 助手：NOVA
- 桌面应用名称：星研工作台
- 技术仓库名、应用 ID、接口字段和数据库表名：保持不变

## 修改范围

1. 登录页、工作台首页、顶部栏、页脚和无障碍标签中的产品名称。
2. 浏览器页面标题、前端 README 标题和相应前端测试断言。
3. Electron `productName`、主窗口标题、托盘名称、托盘菜单和启动错误提示。
4. 仅更新当前运行界面与应用元数据，不批量重写历史需求、规格和实施文档。

## 明确不修改

1. PostgreSQL 中默认多维表格工作区“研发工作台”的业务数据名称。
2. 后端创建默认工作区的名称及依赖该业务名称的测试夹具。
3. 短信服务商已经备案或由用户配置的“研发工作台”签名。
4. Electron `appId`、包名、路由、API、数据库字段和仓库目录名。

## 验收标准

1. 登录页、首页、顶栏、桌面窗口和托盘统一显示“星研工作台”。
2. 浏览器标题包含“星研工作台”。
3. 代码中仍允许存在作为业务数据或历史文档内容的“研发工作台”，但用户可见的产品品牌入口不再显示旧名称。
4. 前端品牌测试、Electron 相关测试、类型检查和生产构建通过。
