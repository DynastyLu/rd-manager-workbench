# NOVA AI 字标串行书写动画设计

## 目标

在知识库 AI 问答的新对话空状态中，为中央输入框增加 “NOVA”
品牌字标，并让 N、O、V、A 严格按顺序完成书写。修复当前 N、A 缺笔和动画卡顿的问题。

## 展示范围

- 字标只显示在没有选中历史会话的新对话页面。
- 字标位于中央输入框正上方，与输入框组成一个居中的整体。
- 已进入对话后不在底部输入框重复展示，避免侵占回答阅读空间。

## 视觉与动画

- 使用自定义内联 SVG 绘制 N、O、V、A 四个完整单线字形，每个字母对应一条
  Motion 路径。N 路径包含左竖、斜线和右竖；A 路径包含两条斜线和完整横杠，
  避免独立短路径的端点被裁切或动画结束状态不一致。
- 线条采用深灰到蓝色的渐变描边，保持现有白色 AI 工作区的克制风格。
- 使用 Framer Motion 的 `pathLength` 驱动路径描边，并用单一时间轴编排四个字母；
  动画直接运行于 SVG 属性，不通过 React 定时更新状态。
- 动画严格串行：N 完成后等待约 140 毫秒再写 O，O 完成后再写 V，V 完成后再写 A。
  任意时刻只允许一个字母处于绘制状态。
- 推荐时序为 N 1.06 秒、O 0.92 秒、V 0.72 秒、A 1.02 秒，总时长约 4.4 秒。
- 播放一次后保留完整字标，不自动循环，避免持续动画干扰输入。
- 字标下方保留很轻的 “LOCAL KNOWLEDGE ASSISTANT” 副标题，用于说明 NOVA 的角色。

## 可访问性

- 外层提供 `aria-label="NOVA"`，SVG 动画本身标记为装饰内容。
- 开启 `prefers-reduced-motion: reduce` 时禁用逐笔动画并直接展示完整字标。
- 字标不获取键盘焦点，不干扰输入框操作。

## 技术边界

- 复用项目现有 `framer-motion` 依赖，不新增 Canvas、字体文件、图片或第三方动画依赖。
- 不修改后端、AI 请求和会话数据结构。
- NOVA 字标和机器人分别使用独立展示组件；机器人在思考过程、临时回答、无结果回答和历史回答中复用。
- 字标动画组件不使用 `setInterval`、逐帧 React state 或 Canvas 重绘，避免主线程频繁提交和高分屏适配成本。

## 组件与数据流

- `NovaWordmark` 负责 SVG 字形、渐变定义、四个 Motion 路径及副标题。
- `KnowledgeChatPanel` 只负责在新对话空状态挂载一次 `NovaWordmark`。
- 四个字母使用同一份只读时序配置，配置包含路径、持续时间和起始延迟。
- 动画完成后不回写会话状态，也不会引起聊天面板重新渲染。

## 字形与边界

- SVG `viewBox` 四周至少保留一个描边宽度的安全边距，N 左边、A 右边不能贴边。
- N 的起点和终点必须完整可见，斜线必须连接两根竖线。
- A 的两侧斜线必须汇合，横杠必须从左斜线内部延伸至右斜线内部。
- 路径使用圆角端点和圆角连接，保持手写落笔感。
- 渐变 `id` 使用 React `useId` 生成，避免页面存在多个实例时发生 SVG 引用冲突。

## 性能与降级

- 优先使用 SVG + Framer Motion；Canvas 只作为实验方案，不进入生产实现。
- 动画只改变 `pathLength` 和轻量透明度，不改变布局尺寸。
- 页面失焦或组件卸载时由 Motion 生命周期自动停止动画。
- 开启减少动态效果时直接显示完整 NOVA 和副标题，不播放串行动画。

## NOVA 机器人

- 思考阶段机器人整体轻微悬浮，天线摆动，光环呼吸。
- 两只眼睛使用相反方向的垂直动画，形成一上一下观察资料的效果。
- “正在思考”后的三个点依次向上跳动。
- 回答完成后继续显示缩小版 NOVA 机器人，不替换为 “AI” 文字。
- 减少动态效果模式下关闭悬浮、眼睛、天线、光环和点状动画。

## 验收标准

1. 新对话页面的输入框正上方显示完整 “NOVA”。
2. 动画严格按照 N → O → V → A 顺序执行，前一个字母结束前后一个字母保持不可见。
3. 字标和输入框在页面中心形成稳定的垂直布局。
4. 历史会话页面不重复显示字标。
5. 减少动态效果模式下字标直接完整显示。
6. 思考中和回答完成后使用同一个 NOVA 机器人视觉身份。
7. N 的三段线条、A 的两条斜线和横杠全部显示，不发生裁切或缺笔。
8. 动画期间不触发逐帧 React state 更新，连续播放时无明显停顿或跳帧。

## 测试策略

- 组件测试验证正好存在四个字母路径，顺序为 `n`、`o`、`v`、`a`。
- 组件测试验证每个字母的开始时间大于或等于前一字母的结束时间。
- 组件测试验证 N、A 路径包含完整的书写段，并使用唯一渐变引用。
- 聊天面板测试继续验证字标只在新对话状态出现。
- 运行前端类型检查、聚焦测试和生产构建。
