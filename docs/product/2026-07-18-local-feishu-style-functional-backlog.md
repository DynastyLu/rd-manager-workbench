# 本地飞书式研发工作台：完整功能清单与交付优先级

**版本：** v1.1  
**产品形态：** Electron 本地桌面应用 + React + NestJS + 本机 PostgreSQL  
**使用方式：** 单人、本机优先；参考飞书的信息组织、交互密度和工作流，不复制飞书品牌、协作或云服务。  
**UI 基础：** 以 Semi Design 作为统一组件基础；多维表格采用 TanStack Table，日历采用 FullCalendar，文档编辑采用 Tiptap，拖拽采用 dnd-kit。现有 shadcn/Radix 仅在迁移期保留，不继续扩大使用范围。

> 本清单以“用户能在本机完成一段真实工作”为完成定义。页面、导航、占位卡片、只有前端的演示数据，均不算功能完成。

---

## 1. 产品边界与统一对象模型

### 1.1 要解决的日常工作

1. 打开应用，知道今天该做什么、什么即将到期、有什么会议或面试。
2. 围绕一个项目持续管理目标、计划、任务、风险、问题、决策、会议和资料。
3. 把会议、文档、复盘、资料和经验沉淀为可搜索、可关联、可版本恢复的知识资产。
4. 用类似飞书多维表格的方式，自定义数据表、字段、筛选和多种视图。
5. 在正确时间收到页面、桌面系统通知；重要事项在后续配置短信后可额外发送短信。
6. 数据全部在本地 PostgreSQL 和本地文件目录中，可搜索、导入导出、备份恢复和审计。

### 1.2 不做的事

- 聊天、群组、组织架构、权限、审批、考勤、邮件、视频会议。
- 多人在线协同、评论/@、共享链接、云端同步、外部日历双向同步。
- 未配置服务商的真实短信发送、AI 自动生成内容、联网情报采集。

### 1.3 统一对象与关联规则

| 对象 | 主要用途 | 必须可关联到 |
| --- | --- | --- |
| 项目 | 研发工作的主空间 | 工作项、会议、文档、文件、知识页、表格记录、日程 |
| 工作项 | 任务、风险、问题、决策、行动项等可推进事项 | 项目、来源对象、相关文档、提醒 |
| 日程/会议 | 有时间的会议、面试、评审和普通安排 | 项目、会议纪要、行动项、文档、提醒 |
| 文档/知识页 | 可编辑的正文资产 | 项目、工作项、会议、文件、表格记录 |
| 文件 | 附件与版本化材料 | 文档、知识页、会议、项目、表格记录 |
| 多维表记录 | 结构化业务数据 | 项目、工作项、日程、文档、其他记录 |
| 提醒/通知 | 到点提示与处理记录 | 任意有时间或需跟进的对象 |

所有关联都必须双向可见；例如，会议行动项转为任务后，会议和任务详情均能打开对方。不得复制多份数据来实现不同页面。

## 3. P0：必须完成的可用核心

P0 的目标是让用户每天可以只使用本应用完成项目推进、个人安排、会议与资料沉淀。

### P0-01 工作台与全局框架

**用户结果：** 打开后 10 秒内知道今天要做什么，并能在任何页面搜索、新建和查看提醒。

- [ ] 飞书式浅色、紧凑桌面壳：左侧应用导航、顶部搜索/新建/通知、主内容区、右侧对象详情抽屉。
- [ ] 统一设计 token：字体、间距、状态色、表格密度、空状态、加载与错误状态；彻底移除深色霓虹和传统后台仪表盘视觉。
- [ ] 工作台：今日行动、待提醒、近期会议、项目脉冲、最近内容、收藏、快捷新建。
- [ ] 每张卡片直接进入真实对象；无数据时只能显示明确的新建入口，不能显示假数字。
- [ ] 全局新建：项目、任务、日程/会议、文档、知识页、表格记录。
- [ ] 全局搜索入口与键盘快捷键：`⌘K/Ctrl+K`；新建 `⌘N/Ctrl+N`。
- [ ] 最近访问、收藏、通知未读数从本地数据库读取。

**验收：** 新建一个任务、会议或文档后，工作台无需刷新即可显示，并可直接打开详情。

### P0-02 项目空间

**用户结果：** 每个项目是一个完整工作空间，而不是一张孤立项目表。

- [ ] 项目列表：新建、编辑、归档、搜索、状态/负责人/阶段过滤、模板创建。
- [ ] 项目详情固定上下文：项目标题、状态、健康度、目标、日期、负责人和快捷新建。
- [ ] 固定页签：**概览｜工作项｜进展｜风险与问题｜会议｜文档与资料**。
- [ ] 概览：目标、里程碑、临近任务、最近进展、健康度、风险摘要、会议和文档摘要。
- [ ] 工作项：表格、看板、日历、甘特四种视图；筛选、排序、分组、行内编辑和拖拽状态。
- [ ] 进展：提交进展、完成百分比、阻塞项、时间线与历史记录。
- [ ] 风险与问题：风险、问题、决策按状态展示；可新建、处置、关闭并转跟进任务。
- [ ] 会议：项目会议列表、新建会议、议程、纪要、行动项和决策。
- [ ] 文档与资料：关联文档、知识页、附件和文件版本。
- [ ] 项目模板：至少“标准研发项目”“轻量事项”“面试/评审跟踪”三类，模板创建后生成对应里程碑、字段与文档模板。

**验收：** 从项目创建会议纪要并生成行动项任务后，可在项目工作项、我的工作、会议详情和全局搜索中看到同一条任务。

### P0-03 我的工作、任务与日历

**用户结果：** 日常计划不会分散在项目、会议和临时记录中。

- [ ] 我的工作固定视图：收件箱、今日、本周、逾期、稍后处理、已完成。
- [ ] 任务完整操作：创建、编辑、完成、取消、延期、优先级、开始/截止时间、子任务、依赖、来源与关联文档。
- [ ] 稍后处理：设置恢复日期；恢复前不出现在今日/本周。
- [ ] 日历月/周/日视图，显示任务截止日、会议、面试、评审和普通日程。
- [ ] 新建/编辑日程：主题、开始/结束、地点或链接、备注、类型、项目、关联文档、提醒规则。
- [ ] 日程详情支持复制、取消、打开关联会议纪要和任务。
- [ ] 支持从日历拖动调整普通日程及任务日期，并记录更新。

**验收：** 新建明天的面试，设置提前 1 天和 30 分钟提醒，日历、待提醒、通知中心和搜索均能找到它。

### P0-04 本地提醒与通知中心

**用户结果：** 到期事项能可靠提示，且用户能查看、稍后处理和追溯通知结果。

- [ ] 通用提醒规则：到点、提前 N 分钟/小时/天、多个提醒点。
- [ ] 后端调度器扫描 PostgreSQL，到点以幂等方式写入 `Notification`。
- [ ] WebSocket 向已打开页面推送；断线后通知中心轮询/刷新未读通知作为补偿。
- [ ] Electron 原生系统通知；应用在托盘后台时继续可用。应用完全退出时，在设置页明确“不保证提醒送达”。
- [ ] 通知中心：未读/已读、打开关联对象、关闭、稍后提醒、发送失败记录。
- [ ] 防重复：同一对象、同一提醒点只能生成一条有效通知；时区、夏令时和系统时钟变化有测试覆盖。
- [ ] 重要事项短信接口预留，但默认关闭；没有服务商配置时绝不发送短信。

**验收：** 设为一分钟后的本地测试提醒后，数据库只有一条通知记录，打开页面与 Electron 均最多各提示一次；稍后提醒产生新的合法时间点。

### P0-05 会议、纪要与行动项

**用户结果：** 会议不是一次性记录，纪要、结论和后续行动会持续跟踪。

- [ ] 会议由日程创建或独立创建；类型：项目例会、评审、面试、外部沟通、其他。
- [ ] 字段：主题、时间、地点/链接、项目、参与说明、议程、纪要、附件、关联文档、提醒。
- [ ] 富文本会议纪要，支持模板、自动保存、版本保存。
- [ ] 行动项逐条转任务，记录 `sourceType=MEETING_ACTION`；重复转换必须识别已创建任务。
- [ ] 会议可创建决策：背景、结论、影响、日期和后续任务。
- [ ] 会议页面、项目会议页、日历和我的工作均展示同一数据源。

**验收：** 完成一次会议纪要后，所有行动项都能转任务且不重复；决策和任务可以回到该会议。

### P0-06 文档、文件与知识库

**用户结果：** 会议、方案、复盘和资料可以沉淀、版本化、关联和找回。

- [ ] 富文本编辑器：标题层级、段落、列表、待办、表格、引用、代码块、链接、图片、附件引用。
- [ ] 文档自动保存、显式版本、版本浏览、恢复、导出。
- [ ] 文档模板：项目计划、会议纪要、周报、项目复盘、技术方案、面试记录。
- [ ] 文件夹、上传、下载、重命名、移动、回收站、恢复、永久删除二次确认。
- [ ] 文件版本：同一文件标识下的版本记录、MIME/大小/hash/时间；文件丢失时能显示修复提示。
- [ ] 知识空间、目录树、知识页、标签、收藏、最近访问、归档、回收站。
- [ ] 知识页可由文档、会议纪要和项目复盘转入，同时保留来源关联。
- [ ] 在项目、会议、任务、文件详情中展示关联知识；知识页反向展示关联对象。

**验收：** 将会议纪要转入知识库、关联项目并上传附件后，可从项目、知识目录、全局搜索和文件详情四处打开同一内容；恢复版本不丢失关联。

### P0-07 多维表格（最小可用版）

**用户结果：** 可用一个数据源做表格、看板、日历和表单，而非在多个模块复制记录。

- [x] 表空间、数据表、字段、记录、视图的完整本地数据模型与 API。
- [x] 首批预置表：项目总表、工作项总表、会议与行动项表、文档与知识资产表、项目风险与决策表。
- [x] 自定义表与字段：文本、多行文本、数字、日期时间、单选、多选、复选、链接、附件、关联记录、创建/更新时间。
- [x] 表格视图：字段显示/隐藏与排序、筛选、排序、分组、冻结主字段、行内编辑。
- [x] 看板视图：按单选/状态字段分组，拖动卡片更新原记录。
- [x] 日历视图：按日期字段显示记录；表单视图：从字段生成录入表单。
- [x] 从预置表打开记录时，应进入对应项目/任务/会议/文档详情，不建立镜像副本。

**验收：** 在任务总表编辑截止日期和状态，会同步更新项目工作项、我的工作和日历；看板拖动后表格值同步变化。

## 4. P1：P0 稳定后完成的效率与治理能力

### P1-01 多维表格高级能力

- [x] 查找引用、公式、双向关联、关联聚合。
- [x] 甘特视图、画册视图、保存筛选、视图权限概念不实现但保存个人视图。
- [x] CSV/Excel 导入预检、字段映射、错误行下载；按当前视图/完整表导出 CSV/Excel。
- [x] 表格模板：合作方台账、研发申报、风险台账、面试候选跟踪、非项目研发记录。

### P1-02 全局搜索与个人效率

- [ ] 全局索引：项目、工作项、会议、日程、文档正文、知识页正文、文件元数据、表格记录。
- [ ] 搜索过滤：类型、项目、时间、状态、标签；高亮命中和最近搜索。
- [ ] 快捷操作：从搜索结果完成任务、创建关联任务、打开抽屉详情。
- [ ] 收藏、最近访问、个人快捷入口与可固定视图。

### P1-03 数据治理、备份与审计

- [ ] 所有核心对象与文件的回收站、恢复和永久删除。
- [ ] 每日自动备份与手动备份：数据库 dump、文件 manifest、版本、校验和。
- [ ] 恢复预检、恢复前快照、失败回滚、存储空间校验。
- [ ] 审计：创建/编辑/删除/恢复、导入/导出、备份/恢复、通知/短信发送结果。
- [ ] 设置：数据库与文件目录健康检查、备份目录、通知偏好、数据导出与隐私说明。

### P1-04 研发辅助对象

- [ ] 合作方、联系人、协议、沟通记录；作为项目关联对象和表格模板，不新增顶级导航。
- [ ] 申报/认定工作项模板：节点、材料、纠正项、提交记录、提醒和关联文档。
- [ ] 非项目研发：学习、技术债、预研、招聘面试等个人/团队事项，可显示在我的工作与日历。

## 8. 后续执行约束

1. 先重构 UI 骨架和项目空间，再扩展旧模块；不再新增后台式顶级菜单。
