# P0-D 多维表格交付记录

**交付日期：** 2026-07-19  
**范围：** `P0-07 多维表格（最小可用版）`

## 已交付

- 本地 PostgreSQL 数据模型：表空间、数据表、字段、记录、视图；新增完整性迁移，保证每张有效数据表只有一个主字段。
- 五张实时预置表：项目、任务、会议与行动项、文档与知识、风险与决策。预置表通过 source adapter 读写原业务对象，不保存镜像记录。
- 自定义数据表、字段和记录 CRUD；字段覆盖文本、多行文本、数字、日期、单选、多选、复选、链接、附件、关联、创建/更新时间。
- 表格视图：搜索、筛选、排序、分组、字段显隐/排序、冻结主字段、行内编辑、原对象跳转。
- 看板、日历、表单视图；视图配置可新增、重命名、保存和删除。
- 任务从多维表格更新后，主动失效“我的工作、任务、日历、项目、工作台、提醒”等查询缓存。
- 文档、文件、会议、风险和决策更新后同步失效其列表、详情与版本缓存；任务、风险和决策来源链接可精确定位到原记录。
- 会议/行动项与风险/决策按实际记录类型限制状态和可编辑字段；后端同时执行写入白名单和值域校验。
- 看板排除全局只读的单选字段，并在记录只读或更新 pending 时禁止重复拖动；表单标记并前置校验全部必填字段，工具栏新增记录直接进入完整表单。

  - 任务日历显示中文月份和星期，且能显示同一任务。

## 明确边界

- Risk/Decision 当前领域接口不支持清空关联项目，会议时间也不可清空；系统现在明确返回 400，不再静默忽略。行动项截止时间和文档关联项目支持清空。
- 公式、查找引用、双向关联、甘特/画册、CSV/Excel 导入导出属于 P1，不计入本次 P0-D。
- 构建仍有既有第三方 `lottie-web` 的 direct-eval 警告和大 chunk 提示，不影响本次功能运行，后续性能治理再处理。
