# 研发工作台：功能完善与效率提升路线

**版本：** v1.0  
**日期：** 2026-07-29  
**目标：** 在现有功能基础上，优先减少重复录入、来回查找、手工汇总和遗漏跟进  
**前置条件：** 先完成《现有功能问题清单》中的 P0 修复

## 1. 产品方向

本地单人版不追求继续堆页面，而是让以下日常流程真正省时间：

1. 工作只录入一次，项目、我的工作、日历、员工周报和报表自动联动。
2. 会议、周报和资料中的行动信息可快速转为任务、风险、进展或知识。
3. 系统主动整理“今天做什么、哪些快延期、哪个项目有变化”，而不是等用户逐页查找。
4. NOVA 不只回答问题，还能生成可审阅的业务草稿；所有写入都必须由用户确认。
5. 主管能在 5 分钟内完成周进展检查和周报输出。

## 3. P0：先做的高收益功能

### FEAT-P0-001 统一工作收集与处理中心

**目的**

现有“我的工作”已经有收件箱视图，但主要承载任务。需要把临时想法、会议待处理内容、资料、文件和提醒统一收进一个待分拣入口。

**功能**

- 全局快捷记录：文字、粘贴内容、文件、截图说明和语音转写结果预留。
- 每条收集项可转换为任务、日程、会议、文档、风险或知识页。
- 支持补充项目、负责人、截止时间和标签后再归档。
- 支持批量分拣、稍后处理、合并重复项和标记无须处理。
- 从会议、NOVA、搜索结果、员工周报中产生的待确认内容也进入同一处理中心。

**验收**

- 在任意页面使用快捷键，30 秒内记录一条事项并转为项目任务。
- 转换后保留来源，收集项不再重复出现在待处理列表。

### FEAT-P0-002 项目计划引擎

**目的**

把已有的项目周期、里程碑、任务依赖和进度计算升级为真正可管理的计划。

**功能**

- 项目工作项内置列表、看板、日历和甘特四视图。
- 计划基线：保存批准版项目周期、里程碑和关键任务。
- 关键路径：根据任务依赖、工期和截止时间计算。
- 计划/实际对比：计划时间、实际时间、延期天数、进度偏差。
- 变更记录：修改项目周期、里程碑或关键任务时填写变更原因。
- 情景预演：移动一个关键任务时预览受影响节点，不立即写库。
- 一键生成项目周进展草稿。

**验收**

- 能从甘特图定位影响最终交付的任务。
- 修改关键任务日期前能看到受影响里程碑，确认后才保存。
- 项目概览清楚展示相对基线的进度和时间偏差。

### FEAT-P0-003 员工周报到项目进展的自动汇总

**目的**

把已完成的员工周报导入和项目关联能力，变成主管可直接使用的项目进展。

**功能**

- 周报导入完成后，按项目自动分组。
- 汇总本周完成、下周计划、未完成、阻塞、风险、计划工时和实际工时。
- 自动识别：
  - 多人重复描述的同一事项；
  - 未关联项目或任务的工作；
  - 完成度下降或长期不变的工作；
  - 超计划工时和资源冲突；
  - 可能影响里程碑的风险。
- 生成“项目进展建议草稿”，用户可逐条采用、编辑或忽略。
- 用户确认后，写入项目进展、风险或任务；保留员工周报行作为来源。
- 自动生成团队周报和月报，可导出 Excel、Markdown 和 PDF。

**验收**

- 一次周报导入后，主管无需逐人复制，5 分钟内可发布全部项目周进展。
- 任何自动汇总内容都能追溯到员工、周期、工作表和原始行。

### FEAT-P0-004 会议前、中、后完整闭环

**目的**

让会议从“记录内容”升级为“准备—记录—执行—复查”的连续流程。

**功能**

- 会前：会议模板、议程、待讨论问题、关联项目状态和上次未完成行动项。
- 会中：纪要快捷块，选中文字可转行动项、决策、风险、问题或知识。
- 会后：行动项批量确认并转任务，自动带负责人、项目和截止时间。
- 行动项与任务状态双向同步。
- 自动生成会议摘要、结论、未决问题和下次会议建议。
- 会议到期未完成行动项进入“我的工作”和通知中心。
- 周期会议自动带入上次会议的未完成项。

**验收**

- 完成一次会议后，所有行动项都有负责人、截止时间和可追踪任务。
- 下次会议打开时自动显示上次未完成行动项，无须手工查找。

## 4. P1：完成核心闭环后的效率功能

### FEAT-P1-001 跨对象活动流与反向关联

**功能**

- 项目活动流统一展示任务、里程碑、进展、风险、会议、文档、员工周报和提醒变化。
- 员工活动流统一展示周报、任务、项目、风险和会议行动项。
- 每个对象显示“关联到我的内容”和“我产生的内容”。
- 支持类型、时间、项目、员工和自动/人工来源筛选。
- 重要活动可固定、评论备注（单人备注，不引入多人协作）。

**收益**

- 不必逐个页签寻找最近变化。
- 所有自动化结果有清晰来源和回退入口。

### FEAT-P1-002 NOVA 可确认业务操作

**目的**

NOVA 从本地知识问答升级为工作助手，但不能在未确认时修改业务数据。

**功能**

- 支持查询范围：全部知识、项目、文件夹、员工、时间段和对象类型。
- 预置能力：
  - 总结项目本周进展；
  - 提取未关闭风险；
  - 从会议纪要提取行动项；
  - 对比两版方案或两期周报；
  - 生成项目周报、月报或复盘草稿；
  - 查找相似历史项目和知识。
- 回答中的事项可转换为任务、风险、会议、项目进展或知识页。
- 写入前展示结构化预览：目标对象、字段、来源、可能重复项。
- 用户逐条确认、编辑或取消后才调用业务 API。
- 保存执行记录，可撤销可逆操作。

**验收**

- NOVA 生成的每个结论都有可打开的引用。
- NOVA 不能直接静默创建或修改业务对象。
- 同一建议重复执行时能够识别已有对象。

### FEAT-P1-003 自动日报、周报、月报和管理简报

**功能**

- 每日工作简报：今日任务、逾期、会议、临近里程碑、待处理风险。
- 项目周报：完成情况、计划偏差、风险、决策、下周计划。
- 团队周报/月报：员工投入、项目分布、完成度、风险和负荷。
- 数据截止时间和统计口径可配置。
- 简报先生成草稿，用户确认后归档为文档或发送到指定渠道。
- 历史简报可比较，突出新增、关闭和持续未解决项。

**验收**

- 简报中的数字能钻取到原任务、员工工作项或风险。
- 同一周期重复生成有版本记录，不覆盖已发布版本。

### FEAT-P1-004 自动化规则与重复工作

**功能**

- 规则结构：触发条件 + 条件判断 + 动作。
- 首批触发：
  - 任务到期/逾期；
  - 里程碑进入预警期；
  - 风险升级；
  - 周报未提交或字段未补全；
  - 会议结束；
  - 文件夹扫描或索引失败。
- 首批动作：
  - 创建通知；
  - 创建/更新任务；
  - 生成简报草稿；
  - 发送短信（配置服务商后）；
  - 将事项加入统一处理中心。
- 重复任务和重复日程支持按日、周、月和工作日生成。
- 规则有运行记录、失败重试、暂停和手动测试。

**验收**

- 用户能配置“里程碑前 7 天且未完成时提醒，并生成跟进任务”。
- 同一触发周期不重复生成通知或任务。

### FEAT-P1-005 决策型报表与异常中心

**功能**

- 图表：项目进度趋势、任务完成趋势、风险变化、资源负荷、周报完整率。
- 同比/环比：本周对上周、本月对上月、自定义周期。
- 钻取：从指标进入对应项目、员工、任务或风险明细。
- 异常中心：
  - 进度落后于计划；
  - 关键路径延期；
  - 高风险长期未处置；
  - 员工超负荷或长期无计划；
  - 周报缺失；
  - 知识索引失败。
- 保存报表视图和筛选条件。
- 定时生成报表快照并归档。

**验收**

- 任何红色指标都能在两次点击内打开造成该指标的明细。
- 导出结果与当前筛选和图表口径一致。

### FEAT-P1-006 智能视图和个人工作区

**功能**

- 保存跨模块筛选：如“本周到期的高优先级项目任务”“我关注的高风险项目”。
- 个人首页可以固定项目、视图、报表、文档和 NOVA 提问模板。
- 最近访问统一由数据库记录，不只依赖浏览器本地存储。
- 快捷命令面板支持搜索、打开、新建、切换视图和执行常用动作。
- 用户可把多维表格视图嵌入项目概览或个人首页。

**验收**

- 常用对象和操作可在键盘命令面板中完成。
- 更换电脑或清理浏览器数据后，固定视图和最近工作仍保留在本地数据库。

## 5. P2：长期复用和外部扩展

### FEAT-P2-001 知识治理中心

- 文件和知识重复检测。
- 标签建议、项目归档建议和失效内容提醒。
- 索引健康、失败修复和来源可用性检查。
- 知识引用反向链接：哪些项目、文档和 NOVA 回答使用过该资料。
- 保留期限、归档和批量迁移。

### FEAT-P2-002 模板中心

- 项目、里程碑、任务、会议、周报、文档和多维表格统一模板。
- 模板可设置默认提醒、默认字段、阶段和必填项。
- 从优秀历史项目生成模板草稿。
- 模板版本化，旧项目不被新模板自动改写。

### FEAT-P2-003 外部触达与数据源

- 短信服务商正式接入、模板审核、费用提示、失败重试。
- 外部日历双向同步和冲突预检。
- WebDAV/云盘增量同步、断点续传和冲突处理。
- 外部 AI 必须显式授权并展示将离开本机的数据范围。

### FEAT-P2-004 多人和 LAN

继续作为独立项目处理：账号、权限、操作冲突、评论、@、共享、审计主体和数据安全需要重新设计，不直接塞入当前单人版。

## 6. 推荐实施批次

| 批次 | 内容 | 交付结果 |
| --- | --- | --- |
| 批次 0：可靠性 | 现有问题清单全部 P0 | 当前核心功能在 Electron 和 Windows 可稳定运行 |
| 批次 1：项目闭环 | 项目多视图、计划基线、关键路径、会议行动同步 | 项目计划与执行形成闭环 |
| 批次 2：管理提效 | 员工周报自动汇总、活动流、日报/周报/月报 | 主管不再逐页手工汇总 |
| 批次 3：NOVA 行动化 | NOVA 范围、业务草稿、确认写入、执行记录 | AI 从查询升级为可控助手 |
| 批次 4：自动化与决策 | 规则引擎、异常中心、钻取报表、智能视图 | 系统主动提醒问题并给出处理入口 |
| 批次 5：长期治理 | 知识治理、模板中心、外部集成 | 提高长期复用和扩展能力 |

每个批次完成后再开始下一个批次，避免同时修改项目、周报、NOVA、通知和报表导致回归范围失控。

## 7. 暂不新增

以下能力当前不会明显提升单人研发主管的核心效率，暂不进入实施：

- 即时聊天、群组、视频会议。
- 多人实时协作文档、评论和 @。
- 复杂审批、考勤、薪资和完整 HR 系统。
- 自建邮件系统。
- 独立移动 App。
- 无明确数据源和验收标准的“全自动 AI 决策”。

## 8. 效率验收指标

| 场景 | 目标 |
| --- | --- |
| 记录临时事项并转任务 | 30 秒内完成 |
| 会议结束后生成全部行动任务 | 2 分钟内完成 |
| 导入员工周报并发布项目周进展 | 5 分钟内完成 |
| 从异常指标定位原始记录 | 最多 2 次点击 |
| NOVA 回答定位引用 | 每条关键结论可打开来源 |
| 重新进入保存视图 | 与离开前完全一致 |
| 文件夹重扫 | 全程可见进度、失败项和恢复动作 |
| 新 Windows 电脑首次启动 | 无需手工修改代码或运行 Prisma 命令 |
